# MUNctl
**A React Native app for managing Model United Nations conferences across platforms (mobile & web).**

> [!CAUTION]
> This project is in the early prototyping phase. Expect frequent changes and unfinished features. Contributions are welcome, but please start with an issue to discuss your ideas.

---

## 🌍 About MUNctl
MUNctl is a modern, intuitive tool to streamline Model United Nations conference management. Designed for organizers and delegates, it offers cross-platform flexibility with optional cloud sync.

---

## 🚀 Features
- **Cross-platform support**: Use on mobile (iOS/Android) or web.
- **Modern UI**: Clean, responsive design for efficient workflow.

### 🔧 In Development
- **AutoRes**: Transform bullet-point notes into LaTeX-formatted resolutions.
- **eVoting**: Real-time voting via a web interface for resolution approvals.
- **Awards System**: Nominate and track delegations for awards like "Best Delegate."

---

## 📱 Installation & Usage
### Setup Instructions
1. Install dependencies:
   ```bash  
   pnpm install  
   ```  
2. Run the app:
      ```bash  
      pnpm dev
      ```  
      For the web preview, open [localhost:8081](http://localhost:8081) after starting the server.

---

## 📝 Usage Examples
- Organize conferences with delegations, committees, and resolutions.
- Generate LaTeX-based AutoRes drafts directly in-app (*in development*).
- Conduct eVoting sessions via the web interface (*in development*).
- Nominate delegates for awards using the built-in system (*in development*).
